WebLibre can now update itself: it checks for new versions, downloads them and installs them from inside the app.

- Find it under Settings > General > Updates, or in the About dialog.
- WebLibre checks once a day and lets you know when a new version is out. Downloading and installing only start when you tap.
- Before you download, you can see what's new, whether the update includes security fixes, and which bundled parts change.
- Every update is checked for a valid WebLibre signature before it is installed, and checks use your proxy or Tor connection.
- Installing closes WebLibre, along with any private tabs.
- The bridges used to connect to Tor have been updated.

This is an alpha release. Back up important profiles before trying it.
